IsoNim Web Components

Reusable custom elements built with IsoNim's reactive system — no framework required.

Counter

A reactive counter with custom events. The badge below updates via inter-component communication.

Toggle

Toggle switches dispatching change events. Toggling "Dark mode" changes the page background.

Badge

Reactive badges that update when attributes change. Try the counter above to see the first badge react.

Todo List

A self-contained task list. Add, toggle, and remove tasks — all state managed inside the Web Component.

Inter-component Communication

Components communicate through standard DOM events. The counter above dispatches count-changed events that update the badge beside it. All wiring is done in a plain <script> tag — no framework glue needed.

Built with IsoNim — isomorphic reactive framework for Nim.
