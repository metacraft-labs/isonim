# M49 Long-Tail CSS and Property Evidence

M49 promotes a bounded set of long-tail property families only when they have
headless schema/source-plan coverage, browser behavior coverage, objective
visual assertions, and Back Office consumer evidence. Rows without that full
chain stay marked as limited or read-only.

| Family                       | Representative properties                                            | Status               | Source write    | Metacraft evidence | Limitation                                                                                                                                                                                                    |
| ---------------------------- | -------------------------------------------------------------------- | -------------------- | --------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| typography                   | `letter-spacing`                                                     | validated            | token or schema | covered            | `text-transform`, `white-space`, `text-overflow`, and OpenType feature editing remain below the full evidence bar.                                                                                            |
| color_and_background         | `background-size`                                                    | validated            | token or schema | covered            | `background-image` has example-browser evidence only; `background-position`, token/literal colors, and asset pickers are not claimed here.                                                                    |
| border_shadow_and_effects    | `border-style`                                                       | consumer_unvalidated | token or schema | not covered        | `border-style` has headless and example-browser evidence, but no Metacraft consumer save coverage. `outline-offset` remains headless/UI-only because editor selection chrome owns the browser outline offset. |
| filters                      | `filter`                                                             | validated            | token or schema | covered            | `backdrop-filter` and `mix-blend-mode` remain headless/UI capabilities only.                                                                                                                                  |
| transforms_and_transitions   | `transform`, `transition-duration`                                   | validated            | token or schema | covered            | `transform-origin`, `transition-timing-function`, `transition-delay`, and animation timelines are not validated here.                                                                                         |
| grid_and_flex                | `flex-wrap`                                                          | consumer_unvalidated | token or schema | not covered        | `grid-auto-flow`, `grid-template-columns`, `gap`, and named-area authoring are not validated here.                                                                                                            |
| overflow_position_and_sizing | `aspect-ratio`                                                       | validated            | token or schema | covered            | `overflow-x`, `overscroll-behavior`, `inset`, `min-width`, and constraint solving remain below the full evidence bar.                                                                                         |
| responsive_variants          | `sm:gap`                                                             | browser_limited      | token or schema | not covered        | The source plan is covered headlessly, but M49 does not add responsive browser assertions or Metacraft consumer saves.                                                                                        |
| pseudo_state_variants        | `hover:background-color`, `focus:outline-offset`, `active:transform` | read_only            | none            | not covered        | Read-only future workflow metadata; M49 does not claim hover, focus, or active browser behavior, visual evidence, or source-plan exercise.                                                                    |
| container_queries            | `container-type`, `container-name`, `@container`                     | read_only            | none            | not covered        | Container-query controls remain read-only until ownership and browser editing are implemented.                                                                                                                |

Evidence is enforced by `tests/test_editor_release_gate.nim` and the
machine-readable rows in `docs/editor-feature-matrix.json`.
